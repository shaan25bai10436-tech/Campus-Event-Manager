# Problem Statement

Campus events often require participant registration, event capacity tracking, points allocation, and house-wise ranking. Managing these operations manually can lead to duplicate registrations, incorrect scores, and difficulty generating a consolidated leaderboard.

## Scope
The project provides a console-based system for participant and event management, registration, points allocation, leaderboard generation, validation, and CSV data storage.

## Target Users
- Student event coordinators
- Hostel/club event committees
- Faculty event coordinators

## High-Level Features
- Participant CRUD-style management
- Event creation
- Event registration
- Points processing
- House leaderboard
- Persistent CSV output
- Error handling
